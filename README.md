# Presupuestos SPetroleros

App web para armar presupuestos del corralón SPetroleros (Barda del Medio) con los precios de D&D Soft y enviarlos por WhatsApp.

- Datos (artículos, clientes, presupuestos, usuarios) en Supabase, protegidos con usuario y clave.
- Precios y clientes se actualizan desde D&D Soft con el favorito "Actualizar precios SP".
